# 常曦家庭健康管理软件 V1.0｜软著基线说明

## 1. 本次固定的软件信息

- 软件全称：常曦家庭健康管理软件
- 软件简称：常曦
- 版本号：V1.0（App 构建版本 `1.0.0`）
- 软件类型：移动应用软件
- 运行平台：iOS / iPadOS
- 开发语言：Swift
- 开发工具：Xcode
- 基线日期：2026-09-28
- 基线范围：常曦原生 iOS 客户端
- 后端范围：不纳入本次 V1.0 登记

以上名称和版本必须与申请表、源程序页眉、说明书封面及正文保持一致。申请人、著作权人、开发完成日期和首次发表状态须由权利人最终确认。

## 2. 为什么本次不需要后端

软件著作权登记要求提交申请表、程序鉴别材料、文档鉴别材料和相关身份证明，并未规定移动 App 必须配套自建服务器或已经上架应用商店。

常曦客户端具有本地数据、内置示例内容、离线演示登录、健康记录、报告、食养、体质识别和确定性的 UI 测试路径，可以独立安装、启动并展示主要功能。因此 V1.0 以客户端作为一个完整软件申请即可。远程玄同接口属于可选扩展能力，不作为本次登记软件能够运行的前提。

申请材料和演示说明中不应把尚未完成线上验收的医生通信、真实预约、真实诊疗或云端 AI 服务写成 V1.0 已交付功能。

## 3. 法定材料要求

依据《计算机软件著作权登记办法》，通常需要：

1. 软件著作权登记申请表。
2. 程序鉴别材料：源程序前、后各连续 30 页；不足 60 页则提交全部。除特定情况外，每页不少于 50 行。
3. 文档鉴别材料：任选一种文档的前、后各连续 30 页；不足 60 页则提交全部。除特定情况外，每页不少于 30 行。
4. 申请人身份证明；存在委托开发、合作开发、职务开发、受让或继承等情况时，另交相应权属证明。

材料按 A4 规格准备。软件名称和版本号在申请表、源代码、文档中必须一致。

官方依据：

- [国家版权局《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)
- [国家版权局公布的软件登记机构与中国版权保护中心登记网站](https://www.ncac.gov.cn/xxfb/bqshfw/bqdj/djjg/202410/t20241018_870052.html)

## 4. 建议提交的 V1.0 文档

建议使用《常曦家庭健康管理软件 V1.0 用户操作说明书》作为文档鉴别材料，内容至少覆盖：

- 软件概述、运行环境和安装启动
- 首次引导与隐私边界
- 首页与常曦月池
- 健康概览、指标记录和报告
- 身体感受及疼痛位置标注
- 常曦食养与中医体质识别
- 服务、个人资料、本地数据导出与清除
- 离线演示方式、异常提示与退出

说明书截图应来自本基线构建，避免混入旧版的大月亮、旧人体轮廓和已删除的解释性文案。

## 5. 提交前仍需权利人确认

- 申请主体：个人还是公司
- 著作权人准确名称及证件信息
- 开发方式：独立开发、合作开发、委托开发或职务开发
- 开发完成日期
- 是否已经首次发表；如已发表，首次发表日期和地点
- 常曦人物、图标、人体图、食养图片等素材的创作或合法授权凭证
- 是否需要对部分源程序申请例外交存或封存

## 6. 基线验收标准

- Xcode 工程可以编译生成 iOS 模拟器 App
- 无后端时仍可通过离线测试路径完成核心界面演示
- 单元测试通过
- 软件名称、版本号、源程序和说明书一致
- Git 提交与软著版本标签可以唯一定位同一份代码
