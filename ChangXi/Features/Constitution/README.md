# 中医体质与六维健康画像

## 产品位置

「健康」首页先进入「我的健康画像」。画像以六段环和六个持续更新的维度呈现：身体状态、治疗用药、生活管理、身心状态、身体功能、健康特点。每一维都按“事实 → 状态 → 需要 → 行动”组织，不把画像做成诊断分数墙。

中医体质属于“健康特点”，不是疾病状态。居民端路径为：

健康画像 → 健康特点 → 中医体质 → 认识九种体质／开始初测 → 初步结果 → 家庭医生确认 → 日常调养计划。

## 判定边界

国家标准 GB/T 46939—2025《中医体质分类与判定》自 2026-04-01 实施，规定九种基本类型，并采用代表性体感问题与等级计分进行标准化判定。本模块的九种类型和五级回答语义与这一框架保持一致；当前 18 题是产品交互原型中的简短体验题，不是对国家标准完整题表和算法的复刻，也不声称输出正式判定。

- 标准信息：https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=827D6D266BA52A2983F93638DA871028
- 市场监管总局发布说明：https://www.samr.gov.cn/xw/sj/art/2026/art_bbc0d96fbbb741a2a66d2f4f7a44fd82.html
- 国家卫健委中医体质分类代码：https://www.nhc.gov.cn/fzs/c100048/202310/16a32e2b1c0b42e99480b945ef10c0dc/files/1733821986220_57440.pdf

界面始终显示“初步倾向”和状态链：常曦初测 → 待家庭医生确认 → 家庭医生已确认。调养计划只给一般生活方式提示，不提供中药、穴位或治疗处方。体验版本的“提交确认”只保存本机状态，不实际发送给医疗机构。

## 原生页面

- `HealthPortraitView.swift`：六维居民健康画像、分层状态和行动入口。
- `ConstitutionViews.swift`：九种体质总览、逐题初测、结果、单项科普、家医确认、调养计划。
- `ConstitutionModel.swift`：九种类型、轻量问题、结果和本地状态。
- `ConstitutionAtlas.imageset`：一张原创 3×3 人物插画图集，九格分别对应平和、气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁和特禀；由 SwiftUI 按格裁切。`ConstitutionArtwork` 同时保留九套原生绘制作为资源缺失时的兜底。体质名称与说明保持原生文本以支持大字体。

正式插画由内置图像生成工具生成。最终提示词要求：九宫格等分、九位中国老年人物、当代水彩与轻 2.5D、月白和低饱和体质主题色、无文字／标志／水印、不仿制 MBTI 构图、不使用中国红和刻板传统医疗符号。

当前 Windows 环境不能运行 Xcode。合并前需在 Mac 上核对 iPhone／iPad 自适应布局、Dynamic Type、深色模式、VoiceOver 阅读顺序和插画裁切。
