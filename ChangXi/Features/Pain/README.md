# 身体感受 · 原生独立模块

## 2026-09-08 深化

默认进入真正的 SceneKit 三维人体：水平360度旋转、上下查看、双指缩放、部位相机靠近，以及表面点选、划线、圈片、撤销与历史回看；可以用大按钮分步旋转。三维坐标和表面法线附着同一模型节点，带版本保存。资源与医学资料出处见 MEDICAL-DESIGN.md。

仍可切回下面说明的四视角插画模式。语音先生成带左右方向的语义候选，确认后进入三维人体复核；用户在表面重新标记后，粗略插画候选会被替换。新增疼痛规律、持续时间、牵扯位置、加重／缓解、活动／睡眠影响，以及本人／家人转述字段；数值未确认时摘要保留未填写状态。

正式入口已放在「健康 → 身体感受」，不增加底部导航层级。`PainLocationView.swift` 文件末尾仍有独立 Xcode Preview。

实现：SwiftUI、Canvas 标记、原生全屏放大、分段视角选择、系统表单和本地文件保存。没有 WebView、HTML 或 Rive。沿用项目的 MoonBackground、ChangXiCharacter、CX 色彩、Card 和玻璃组件。

流程：选择头部／肩颈／胸腹／背腰／手臂／腿脚 → 局部插画标记 → 疼法、强度、开始时间、备注 → 按各个视角核对 → 保存、历史回看。头部额外提供大按钮部位选项。支持 Reduce Motion。

素材：PainHeadAtlas 与 PainBodyAtlas 是两张四视角插画；SwiftUI 按格裁切显示。视角切换为淡入淡出，不是实时三维旋转。素材用于用户描述身体表面位置，未经医学级解剖精度校验，不能推断疼痛来自哪个组织或器官。

记录保存：独立 `changxi-pain-v1.json`，原子写入并启用完整文件保护。读入失败保留原文件且阻止覆盖；保存失败不显示成功。标记保存视角、归一化坐标、部位和素材版本。正式接入时需将其纳入主应用的导出、清除数据、用户切换和迁移流程。

当前环境是 Windows，未运行 Xcode 构建或原生截图验收。这里只进行了源码与素材清单检查，没有把插画预览当作 App 截图。

语音定位：选择部位前和标记页面均可进入“说给常曦听”。复用 SpeechController 的系统语音识别与已有可选云端转写设置；也可直接输入文字。停止录音、等待转写结束后点“请常曦标出来”，根据常见表面部位词表提出候选点；可朗读确认问题、点图调整、重说。只有点击“对，就是这里”才进入三维复核，用户完成新的三维标记后才替换粗略候选。缺少左右、多位置、否定或纠正句不自动定位。词表现覆盖头面、肩颈、胸腹、背腰、手臂和腿脚的常见部位，但不是通用大模型理解或诊断。
