# 身体感受 · 原生独立模块

## 2026-09-11 温和标注改版

新记录默认使用无性别、无五官、无解剖层的 SwiftUI 矢量体表图。入口先展示完整正背面轮廓，再选择头部、肩颈、胸腹、背腰、手臂或腿脚，不再用齐口切断的人体局部缩略图，也不再让骨骼／肌肉模型成为主入口。

标注工具保留点状、片状、走向和放射四种。点状提供中心点和柔和光晕；片状改成涂抹笔刷，不要求用户闭合一圈；走向使用双层圆角线；放射明确显示起点、方向和扩散终点。每个视角可以撤销上一笔或单独清空，并保留放大细标。语音候选直接落在同一张体表图上供本人调整。

正式入口已放在「健康 → 身体感受」，不增加底部导航层级。`PainLocationView.swift` 文件末尾仍有独立 Xcode Preview。

实现：SwiftUI 矢量 Path、Canvas 标记、原生全屏放大、分段视角选择、系统表单和本地文件保存。没有 WebView、HTML、Rive 或新位图依赖。沿用项目的 MoonBackground、ChangXiCharacter、CX 色彩、Card 和玻璃组件。

流程：选择头部／肩颈／胸腹／背腰／手臂／腿脚 → 局部插画标记 → 疼法、强度、开始时间、备注 → 按各个视角核对 → 保存、历史回看。头部额外提供大按钮部位选项。支持 Reduce Motion。

新记录的底图由代码原生绘制，视角切换为淡入淡出，不是实时三维旋转。旧版 SceneKit／BodyParts3D 资源仍只用于回看已经保存的三维表面坐标，避免历史记录丢失；新流程不会展示解剖层。底图只用于描述身体表面位置，未经医学级解剖精度校验，不能推断疼痛来自哪个组织或器官。

记录保存：独立 `changxi-pain-v1.json`，原子写入并启用完整文件保护。读入失败保留原文件且阻止覆盖；保存失败不显示成功。标记保存视角、归一化坐标、部位和素材版本。正式接入时需将其纳入主应用的导出、清除数据、用户切换和迁移流程。

当前环境是 Windows，未运行 Xcode 构建或原生截图验收。这里只进行了源码与素材清单检查，没有把插画预览当作 App 截图。

语音定位：选择部位前和标记页面均可进入“说给常曦听”。复用 SpeechController 的系统语音识别与已有可选云端转写设置；也可直接输入文字。停止录音、等待转写结束后点“请常曦标出来”，根据常见表面部位词表提出候选点；可朗读确认问题、在体表图上调整或重说。缺少左右、多位置、否定或纠正句不自动定位。词表现覆盖头面、肩颈、胸腹、背腰、手臂和腿脚的常见部位，但不是通用大模型理解或诊断。
